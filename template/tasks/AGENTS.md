# Local planning

- Keep task notes in dated folders under `tasks/`. Put durable documentation in the owning repository.
- Record each task folder, tracking link, and current status in `tasks/INDEX.md`. Update the path when archiving a task.
- Once work has a tracking issue, add `> Tracked in: <URL>` to its note. Use the issue as the shared record.
- Read generated issue mirrors and roadmap summaries as reference. Edit the source issue or local roadmap graph as appropriate.
- Keep this directory local.
